Carlsbad, California, 2022

The GPUs were not the slow part. The queue was.

Serving a language model then meant handing an engine a batch of requests and waiting for all of them. Gyeong-In Yu and four colleagues at Seoul National University and FriendliAI wrote down the cost: "requests that have finished earlier … cannot return to the client, while newly arrived requests have to wait until the current batch completely finishes."

One user asking yes-or-no is held hostage by a neighbour writing an essay. The fix was one sentence: schedule at the granularity of an iteration, not a request. Run the batch for one token. Then decide again who is in it.

They measured it on GPT-3 175B, partitioned across 16 A100s — two Azure ND96asr v4 machines, list price $27.197 an hour each. At the same median latency of 190 ms per generated token, NVIDIA FasterTransformer served 0.185 requests a second and Orca served 6.81 — a 36.9× speedup. Same silicon. Scheduling alone.

Then the cost moved. A batch whose membership changes every token forces the scheduler to ask, every token, whether there is key-value cache left for one more. Orca's answer was to reserve max_tokens slots of GPU memory the instant a request was admitted — room for every token it might ever hold, not the ones it used. The schedule had become elastic. The memory behind it had not.
